# CRM UI Standalone

نسخة مستقلة من واجهة مستخدم نظام CRM تعمل بدون اتصال بالباك إند.

## الميزات

- ✅ واجهة مستخدم كاملة
- ✅ بيانات تجريبية (Mock Data)
- ✅ عمل بدون اتصال بالإنترنت
- ✅ حفظ البيانات في localStorage

## التشغيل

```bash
# تثبيت التبعيات
npm install

# تشغيل وضع التطوير
npm run dev

# بناء المشروع
npm run build
```

## هيكل المشروع

```
crm-ui-standalone/
├── src/
│   ├── mock/           # بيانات وخدمات تجريبية
│   │   ├── api.ts      # خادم API محاكي
│   │   ├── auth.ts     # مصادقة تجريبية
│   │   ├── data.ts     # بيانات تجريبية
│   │   └── database.ts # قاعدة بيانات محاكية
│   ├── components/     # مكونات React
│   ├── services/       # خدمات API (محاكاة)
│   ├── hooks/          # خطافات مخصصة
│   ├── lib/            # مكتبات ودوال مساعدة
│   └── app/            # صفحات التطبيق
└── package.json
```

## ملاحظات

- جميع البيانات محفوظة في localStorage
- لا يوجد اتصال بقاعدة بيانات حقيقية
- مناسب للعرض التوضيحي والاختبار
